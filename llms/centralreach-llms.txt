# CentralReach

> CentralReach is a healthcare software and services platform for organizations serving children and adults with autism and related intellectual and developmental disabilities (IDD). It provides an integrated practice-management and EMR system covering clinical data collection, scheduling, note drafting and auditing, claims and billing, staff training, and caregiver engagement. The gated Enhanced API (OAuth 2.0 client-credentials + JWT) connects the platform to third-party applications.

## APIs

- [CentralReach Enhanced API](https://centralreach.com/resources/api/): Partner API for secure platform integration. Base URL https://partners-api.centralreach.com/enterprise/v1/. Auth: OAuth 2.0 client-credentials (token endpoint https://login.centralreach.com/connect/token) returning a 1-hour RS256 JWT, plus an organization x-api-key header.
